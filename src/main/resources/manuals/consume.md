# 자체소비 유형 기준

## 폐기
유통기한이 지났거나, 파손·변질되어 판매할 수 없는 상품을 버릴 때 "폐기"를 선택한다.

## 내부 사용
매장 운영을 위해 상품을 직접 사용할 때 "내부 사용"을 선택한다. 예를 들어 직원이 업무용으로 쓰거나, 매장 시음·테스트용으로 사용하는 경우다.

## 샘플 제공
고객이나 거래처에 무료로 상품을 제공할 때 "샘플 제공"을 선택한다.

## 자체소비와 손익
세 유형 모두 매출이 없고, 소비 당시 매입단가 × 수량이 소비 손실로 집계된다. 손익 화면의 최종 이익은 판매 이익에서 이 소비 손실을 뺀 값이다.
유형은 손실 금액 계산에 영향을 주지 않지만, 어떤 이유로 손실이 생겼는지 구분하는 기록이므로 정확히 선택한다.
